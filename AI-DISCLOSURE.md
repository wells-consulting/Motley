# How this code was written

I'd rather say this up front than have it come up in a comment thread.

The code here is a mix of three things: code I wrote by hand, refactoring done with an AI agent, and code an AI agent generated.

The agent configuration files are checked in, so you can see how the agents were set up. Any commit an agent helped with ends in a footer  naming the model. If a commit has no footer, I most likely wrote the code myself and just didn't write a long commit message.

I make every effort to read, test, and understand every line of AI-generated code before I commit it. If something here is broken, that's on me, not on any  tool.
